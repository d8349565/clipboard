# ClipHist 剪贴板历史工具

ClipHist 是一个 Windows 剪贴板历史管理工具，常驻系统托盘，自动记录复制内容，方便随时查找和复用。

## 功能特性

- **多类型记录**：支持文本、文件列表、图片、HTML、RTF、链接等剪贴板内容
- **快速搜索**：输入关键字即可筛选历史记录
- **分类筛选**：按文本/文件/图片/HTML/RTF/链接类型一键过滤
- **一键复用**：双击记录即可写回剪贴板，直接粘贴
- **收藏管理**：收藏重要记录，支持拖拽排序和删除
- **文本编辑**：右键可直接编辑文本记录内容
- **暂停监听**：可临时暂停剪贴板记录
- **历史条数**：可配置保留的历史记录数量
- **窗口尺寸**：面板宽高可自定义
- **开机自启**：支持开机自动运行
- **数据持久化**：重启后历史记录依然保留，数据库位置可自定义

## 安装运行

### 方式一：直接运行源码

```powershell
# 安装依赖
python -m pip install -r requirements.txt

# 启动程序
python run.py
```

### 方式二：使用打包脚本生成 EXE

```powershell
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```

生成的 EXE 文件位于 `dist\ClipHist.exe`。

## 快捷键

| 功能          | 默认快捷键 |
| ------------- | ---------- |
| 打开面板      | `Alt+C`  |
| 暂停/恢复监听 | `Alt+P`  |

> 如果快捷键被其他软件占用，程序会自动尝试其他可用组合。你也可以在设置中手动修改快捷键。

## 使用方法

1. 按 `Alt+C` 或点击托盘图标打开面板
2. 在搜索框输入关键字筛选历史记录
3. 双击某条记录，将内容写回剪贴板
4. 右键文本记录可直接编辑内容

## 设置项

在面板中点击”设置”可修改：

- 打开面板快捷键
- 暂停监听快捷键
- 历史记录保留条数
- 开机自启
- 面板宽度 / 高度
- 数据库文件位置（留空则使用默认位置）

**快捷键格式**：`Ctrl/Alt/Shift/Win + A-Z/0-9/F1-F24/方向键`

## 数据存储

| 文件       | 路径                                   |
| ---------- | -------------------------------------- |
| 配置文件   | `%APPDATA%\ClipHist\config.json`     |
| 收藏记录   | `%APPDATA%\ClipHist\favorites.json`  |
| 历史数据库 | `%APPDATA%\ClipHist\history.sqlite3`（默认，可在设置中自定义） |

> 在设置中更改数据库位置后，已有历史会自动迁移到新位置。清空历史会自动回收数据库占用的磁盘空间。

## 常见问题

**看不到历史变化**

- 确认未处于”暂停监听”状态
- 某些应用会限制剪贴板读取，属于系统行为

**快捷键无反应**

- 可能与其他软件冲突，请在设置中更换快捷键

**启动报依赖缺失**

- 重新执行：`python -m pip install -r requirements.txt`

## 退出程序

在托盘菜单点击”退出”。直接关闭面板窗口不会退出后台进程。
